## Prerequisites

- [Bun](https://bun.sh) >= 1.0
- A Claude API key (`ANTHROPIC_API_KEY`)
- NATS server running (`ravi setup` reuses one that already answers, or downloads nats-server and starts it as `ravi-nats`)
- Omni is not needed for WhatsApp. It is an optional legacy bridge for Telegram/Discord only.

## Installation

```bash
# Clone the repo
git clone https://github.com/filipexyz/ravi.git
cd ravi

# Install dependencies
bun install

# Run setup wizard (NATS, optional legacy bridge, auth, agent, daemon + channel runner)
ravi setup
```

## Configuration

Configure environment in `~/.ravi/.env`:

```bash
# Required
ANTHROPIC_API_KEY=sk-ant-xxx

# Legacy Omni bridge (only for Telegram/Discord)
# OMNI_API_URL=http://127.0.0.1:8882
# OMNI_API_KEY=your-omni-api-key

# NATS (default: nats://127.0.0.1:4222)
NATS_URL=nats://127.0.0.1:4222
```

See [Configuration](/start/configuration) for all environment variables.

## Start the Daemon

```bash
# Start the daemon, then the channel runner (both managed by PM2)
ravi daemon start
ravi channels start

# Check status
ravi daemon status

# View logs
ravi daemon logs -f
```

## Connect WhatsApp

```bash
# Create and connect an instance (served by the ravi channels runner)
ravi instances connect main --agent main
```

Scan the QR code with WhatsApp on your phone (WhatsApp > Linked devices). Check it with `ravi instances status main` and `ravi channels status`.

## Test Your Agent

```bash
# Send a prompt to an agent session
ravi sessions send agent:main:main "oi, tudo bem?"

# Interactive TUI
ravi tui
```
