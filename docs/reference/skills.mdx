# Skills

`ravi skills` installs, lists and inspects Ravi skills.

The default source is the official Ravi skill catalog generated from:

```text
src/plugins/internal/**/skills/*/SKILL.md
```

External sources are explicit and use `--source`. A source can be a GitHub shorthand, GitHub URL, git URL, or local path.

## List Catalog Skills

```bash
ravi skills list
ravi skills list --json
```

## List Installed Skills

```bash
ravi skills list --installed
ravi skills list --installed --codex --json
```

## List Skills In A Source

```bash
ravi skills list --source vercel-labs/skills
ravi skills list --source https://github.com/vercel-labs/skills/tree/main/skills/find-skills
```

## Show A Skill

```bash
ravi skills show image
ravi skills show image --installed
ravi skills show find-skills --source vercel-labs/skills
```

## Install

`skills install` uses a small risk-based matrix:

| Situation | Without `--execute` | Next step |
|---|---|---|
| Additive install from the official catalog or a local path (no `--overwrite`) | installs immediately (exit 0) | verify the result; do not repeat with `--execute` |
| Git source (GitHub shorthand/URL or git URL) | minimal dry-run (exit 3) before resolving the remote source | review the plan, then repeat with `--execute` |
| Any source with `--overwrite` | minimal dry-run (exit 3) before replacing files | review the plan, then repeat with `--execute` |

`sourceLabel` is a controlled category: exactly `catalog`, `local`, or `git`, never a label derived from the input. The plan does not repeat a URL, local path, source/repository/skill name, or content. Git selection is intentionally deferred until the confirmed run.

```bash
ravi skills install image                         # additive catalog install: runs now
ravi skills install my-skill --source ./my-skills # additive local install: runs now
ravi skills install find-skills --source vercel-labs/skills # Git: dry-run (exit 3)
ravi skills install find-skills --source vercel-labs/skills --execute
ravi skills install image --overwrite             # overwrite: dry-run (exit 3)
ravi skills install image --overwrite --execute
```

If a catalog/source contains multiple skills, installation is explicit: pass a skill name or `--all`.

Installed operator skills live in:

```text
~/ravi/plugins/ravi-user-skills/skills/<skill>
```

After install, the CLI syncs materialized Codex skills automatically unless `--skip-codex-sync` is passed.

## Sync

```bash
ravi skills sync
```

Use this when plugin skill files changed on disk and you want the materialized skills directory refreshed immediately.
