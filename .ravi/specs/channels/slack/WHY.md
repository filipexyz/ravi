# Why Slack Native Channel Exists

Slack has first-class workspace, channel, DM, thread, file, Canvas and assistant status semantics that cannot be accurately represented as generic Omni behavior.

Ravi needs Slack as a native channel so routes, sessions, identity, files, operations and status projection follow Ravi semantics while using Slack-native APIs where available.

Omni-backed Slack behavior may remain as migration compatibility, but new Slack-facing features should target the native adapter.
