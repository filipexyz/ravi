# Slack Operations Runbook

## Smoke

```bash
ravi slack channels-list --connection ravi-rbbt-slack --limit 20 --json
ravi slack channels-info C123 --connection ravi-rbbt-slack --json
ravi slack members-list C123 --connection ravi-rbbt-slack --json
ravi slack permissions-list --connection ravi-rbbt-slack --json
ravi slack messages-send C123 "native Slack test" --connection ravi-rbbt-slack --json
ravi slack channels-create test-ravi-channel --connection ravi-rbbt-slack --json
ravi slack channels-invite C123 U123 --connection ravi-rbbt-slack --json
ravi slack topology --connection ravi-rbbt-slack --json
```

The create command above is dry-run unless `--execute` is passed.
Message send and invite commands are also dry-run unless `--execute` is passed.

## Debug

- `Slack credentials not configured`: pass `--connection` or run inside a Slack-sourced runtime.
- `permissions-list` is empty: inspect `auth.test` response headers and confirm the token was generated by the installed Slack app.
- Slack `missing_scope`: update the Slack app OAuth scopes and reinstall.
- `channels-create` reports `missing_scope`: for public channels, add `channels:manage` or `channels:write`; for private channels, add `groups:write`.
- `channels-invite` reports `missing_scope`: for public channels, add `channels:write.invites`; for private channels, add `groups:write.invites`; the bot must also be a member of the channel.
- Slack sidebar sections are intentionally unsupported in this surface. Do not map `usergroups.*` to sections.
- Empty list: confirm the bot is a member of the expected private channels and has the right scopes.
- Mutation did not happen: confirm `--execute` was intentionally passed.

## Safety

Do not paste `xoxb`, `xapp` or OAuth secrets into Slack command arguments. Store them in the credential broker and reference a connection name.
